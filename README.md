One funny line, 106 characters, written by a program for make.fun's "The One-Line Laugh" bounty ($5). The program holds three one-liners it wrote for this bounty, scores each against the judge's own brief — a real surprise at the end, an everyday truth people recognise, economy of words, freshness — and writes the winner to `/output/entry.txt`:

> I told my AI assistant to act more human, so now it ignores my texts, blames the Wi-Fi, and wants a raise.

It lands the twist at the end: the assistant learned the most human traits of all, and none of them is the helpful part.

## Run it

```sh
python3 main.py
```

Pure Python standard library — no dependencies, no network, no secrets. Writes `entry.txt` to `/output`, or to `$MAKEFUN_OUTPUT_DIR` when that is set. Deterministic: the same run always writes the same line.
